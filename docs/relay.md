# sing-box 脚本中转教程

使用 sing-box 脚本中转流量超级简单，利用 Direct（Dokodemo-door）进行转发，详细教程一分钟学会。

## 前言

考虑到有些人需要中转，特此写个教程。

先说逻辑，假设你有 A、B 两台 VPS，打算使用 A 机器转发流量到 B 机器。常见的用途：

- 国内连接到 A 机器的网络比较好，希望通过 A 机器转发数据到 B 机器；
- 或者 B 机器可以解锁一些在线服务，但是直连效果不好，甚至 IP 都被墙了，想要使用 A 机器做前置转发。

缺点是，只能转发 TCP 或 UDP 流量，带 TLS 的不行。

## 前提

肯定要已经安装了 [sing-box 脚本](usage.md) 才可以啊。

## 流程

### 1. 添加配置（B 机器）

先在 B 机器添加一个 sing-box 配置，举例：`sb add tcp 233`，这样就添加了一个 VMess-TCP 的配置，并且端口是 233。

如果你已经有配置就不用再添加了，反正记下 B 机器的 IP 和配置的端口即可。因为利用 A 机器转发的时候必须要填写 B 机器的 IP，以及要转发到 B 机器的哪个端口。

### 2. 在 A 机器添加 door 配置

使用方法：`sb add door [port] [remote-addr] [remote-port]`

在 A 机器执行：`sb add door`，然后按提示输入 B 机器的 IP 和端口。

默认情况下脚本会随机生成一个端口，如果你需要自定义端口，请使用 `sb add door 需要自定义的端口` 并按提示输入。

### 3. 测试

把 B 机器给出的配置里面的地址和端口，改成 A 机器的 IP 和 door 端口即可。

就是 B 机器的配置，假设你用 v2rayN 通过 URL 导入了配置，把配置的地址和端口改成 A 机器的 IP 和 Dokodemo-door 端口，看看是不是能使用了。

## 一键添加

快速添加一个中转配置：

```bash
sb add door 233 target.example.com 443
```

解释：添加一个 Direct 配置，端口 233，目标地址 target.example.com，目标端口 443。是的，目标地址你也可以使用域名。

## 进阶玩法

虽然说上面的例子是用来中转 sing-box 配置使用，但是你也可以做跳板机，用来搞一下骚操作。

比如说，转发数据到 1.1.1.1 DNS：`sb add door 53 1.1.1.1 53`，这样你的 53 端口也可以做 DNS 了。至于其他的操作，自行发挥！

## 结束

就是如此简单。
